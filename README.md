# Thermal-Stand
Тепловой стенд это моя тема курсового проекта по предмету "Технические средства систем управления". В ТЗ входят следующие пункты:
1.	Провести проектирование, выбор и обоснование структуры и приборного состава
2.	Рассмотреть конструкцию и принцип действия элементов Пельтье
3.	Реализовать алгоритм регулирования температуры на макете
4.	Провести анализ результатов макетирования

Сам тепловой макет был выдан мне уже готовым, но "инструкция" к нему в виде дипломной работы была утеряна. 
Мне предстоит разобраться в его работе и доработать.
Этот репозиторий служит для отслеживания собственного продвижения и некой методички по работе с этим макетом.
